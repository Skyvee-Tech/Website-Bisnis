Yang perlu dibawa

  • Laptop dan chargernya. Banyak kasus “mati total” ternyata hanya masalah adaptor atau baterai.
  • Catatan gejala. Kapan mulai terjadi, apa yang dilakukan sebelum muncul, dan pesan error yang tampil.
  • Password laptop atau akun yang diperlukan untuk mengecek sistem. Kalau tidak nyaman memberikan password asli, buat password sementara.
  • Backup file penting jika memungkinkan. Untuk install ulang, data di drive C akan hilang.

Berapa lama pengerjaannya?

Install ulang biasanya sekitar 1 jam, tergantung kecepatan perangkat dan jumlah update. Kerusakan hardware perlu dicek dulu, jadi waktunya tidak bisa dipastikan sebelum diagnosis. Kalau pengerjaan memakan waktu, kami kabari lewat WhatsApp.

Soal biaya

Kami sampaikan temuan dan estimasi biaya setelah pengecekan, lalu Anda putuskan sebelum pengerjaan dimulai. Tidak ada biaya yang muncul belakangan tanpa persetujuan.

Data dan privasi

File pribadi tidak dibuka tanpa izin. Kalau Anda ingin data tertentu tidak disentuh, sampaikan sejak awal. Untuk install ulang, simpan dulu file penting atau tanyakan opsi backup sebelum pengerjaan.

Kalau tidak bisa datang

Anda bisa chat lebih dulu dan mengirim foto atau video singkat tentang kondisi laptop. Dari sana kami bantu menilai apakah perlu dibawa ke tempat atau cukup diarahkan. Untuk opsi antar-jemput, tanyakan langsung ketersediaannya lewat WhatsApp.

Kirim gejala dan tipe laptop Anda. Kami bantu perkirakan langkah dan kebutuhannya.
